BullseyeCoverage README

Quick Installation
==================
To install into /opt:

	sudo ./install --key <licenseKey> --search "$PATH"

Advanced Installation
=====================
Invoke "./install --help" to see additional options.

To use the license manager see https://www.bullseye.com/help/licenseManager.html "Setting up on Unix-like Systems"

Documentation
=============
The documentation is in the directory help/.  View the documentation with an
HTML browser via help/index.html.  You can also see the latest version of the
documentation at https://www.bullseye.com/help/.

Uninstalling
============
To uninstall, remove the installation directory, for example:

	sudo rm -fr /opt/BullseyeCoverage
